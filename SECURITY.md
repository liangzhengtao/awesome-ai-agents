# Security Policy

## Reporting a Vulnerability / 报告漏洞

If you discover a security vulnerability in this project, please report it responsibly.

如果你发现本项目存在安全漏洞，请负责任地报告。

### Do NOT open a public issue. / 不要公开提交 issue。

Instead, please email: **security@liangzhengtao.dev** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You should receive a response within 48 hours.

### What to expect:

1. **Acknowledgment** — within 48 hours
2. **Assessment** — we'll evaluate the severity
3. **Fix** — critical issues will be patched ASAP
4. **Disclosure** — we'll coordinate with you on public disclosure

## Scope / 范围

This project contains documentation and code templates. Security concerns primarily relate to:

- **Code templates** that might encourage insecure patterns
- **Dependencies** in example code
- **Prompt injection** patterns in agent code

We take all security feedback seriously, even for documentation-only projects.
